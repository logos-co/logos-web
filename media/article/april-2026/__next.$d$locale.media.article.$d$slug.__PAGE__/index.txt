11:T67f5,<h2 id="logos-testnet-v0-1-2-now-live">Logos Testnet v0.1.2 now live</h2><p>In April, Logos released Testnet v0.1.2, introducing key improvements following feedback from the initial public testnet. The new release enhances bootstrap efficiency, making it faster and more reliable, while also optimising log storage to reduce excessive disk usage and address the main issues node operators faced in v0.1.&nbsp;</p><p>This update requires node operators to upgrade and rejoin the network, as the testnet has been reset with a new genesis block. If you’re running a node or looking to get started, now is the time to jump in and take advantage of the improved performance and stability.</p><p>Running Logos Testnet offers an opportunity to be at the forefront of a new blockchain designed to support truly decentralised applications running on user-controlled hardware, with a strong focus on agency and privacy. By participating in the testnet, you can help test network performance and provide valuable feedback.&nbsp;</p><p><a target="_blank" rel="noopener noreferrer" href="https://build.logos.co/">Join Logos Testnet v0.1.2 via the Logos Builder Hub.</a></p><p><i>Please note: Logos Testnet is experimental software. As such, it may contain bugs, incomplete features, or breaking changes between versions. Participants should be prepared for resets and ongoing updates as the network evolves.</i></p><h3 id="testnet-v0-1-stats">Testnet v0.1 stats&nbsp;</h3><p>With the launch of Testnet v0.1.2, we published a&nbsp;<a href="/media/article/testnet-v0-1-review">detailed review of Testnet v0.1</a>, assessing how the blockchain performs under real-world conditions. Overall, the testnet proved more resilient than expected.&nbsp;</p><p>Over six weeks, the network processed more than 222,000 transactions across over 186,000 blocks, with 357 nodes run by participants in 29 countries. Europe led participation with 74% of nodes, while the network maintained an average block time of 19 seconds, closely matching its 20-second target, an encouraging early signal of stability.</p><figure class="image"><img style="aspect-ratio:2100/1500;" alt="lpe-logos-blockchain-review-block_times.png" src="/media-images/lpe_logos_blockchain_review_block_times_069bb50f07-fd4502fd-750.webp" srcset="/media-images/lpe_logos_blockchain_review_block_times_069bb50f07-fd4502fd-750.webp 750w, /media-images/lpe_logos_blockchain_review_block_times_069bb50f07-fd4502fd-1400.webp 1400w" sizes="(max-width: 767px) calc(100vw - 32px), 700px" width="2100" height="1500" loading="lazy" decoding="async"><figcaption>Block time distribution for the longest chain on Testnet v0.1.</figcaption></figure><p>The report also highlights key challenges, including long node bootstrapping times and high log storage requirements, both of which are addressed in the v0.1.2 release.</p><p><a href="/media/article/testnet-v0-1-review">Read the full review to explore the data, insights, and what’s next for the Logos stack</a>.</p><h2 id="prize-rewarding-developers-building-on-logos">λPrize: Rewarding developers building on Logos</h2><p>In April, we launched the λPrize, a builder incentive programme offering up to $500,000 in rewards for developers who create real, working applications on the Logos tech stack.
