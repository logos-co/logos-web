10:T26e4,<p>Logos Testnet v0.3 was released on 30 September 2026. The release brings improvements across almost every part of the stack, affecting everything from how new participants join the network to how files and messages move privately between peers.</p><p>To try out the new features in Logos Testnet v0.3, download and install&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://github.com/logos-co/logos-basecamp/releases/latest">the latest release of Basecamp</a>.</p><p>Node operators should update their clients to the latest version with the launch of Testnet v0.3, and developers will need to update existing LEZ programs, as breaking changes have been introduced by significant improvements to the state update model.</p><p>This article outlines the key highlights of the changes introduced in Testnet v0.3, along with a brief look at what these new features do.</p><p>Information on running a node on Testnet v0.3 can be found in the&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://docs.logos.co/run-a-node">node operator guide</a>.</p><p>View the full list of updates in the&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://roadmap.logos.co/testnets/v03-release">release notes here</a>. Below are the key highlights included in Testnet v0.3.</p><h2 id="proof-of-work-participation-with-empowering">Proof-of-work participation with EmPoWering</h2><p>To take part in a proof-of-stake network, you first need testnet tokens, which usually come from a faucet run by the project.&nbsp;</p><p>EmPoWering adds another route in, letting new participants take part in Logos Blockchain by performing computational work and receiving testnet tokens from the network for such work. &nbsp;</p><p>This removes centralised, traceable on-ramps to the network and means nobody needs to approve a request before a new participant can hold tokens and start transacting.</p><p><a target="_blank" rel="noopener noreferrer" href="https://lip.logos.co/blockchain/raw/proof-of-work.html">Read the full LIP for Proof-of-Work participation on Logos</a>.</p><h2 id="decentralised-sequencing-for-the-lez">Decentralised sequencing for the LEZ</h2><p>A sequencer decides the order in which transactions are included, and many layer-2s rely on a single sequencer that can see every transaction before it is final and halt the network if it goes offline.&nbsp;</p><p>The Logos Execution Zone (LEZ) now supports decentralised sequencing, where a set of sequencers take turns proposing blocks on a schedule enforced by Logos Blockchain.&nbsp;</p><p>Each sequencer checks the blocks produced by the others, applying valid ones and rejecting the rest. Indexers also rebuild the zone's state independently, so a sequencer cannot pass off a forged or replayed transaction.</p><p>For more on how decentralised sequencing is used in Logos Blockchain,&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://lip.logos.co/blockchain/raw/bedrock-v1.1-mantle-specification.html#decentralized-sequencing">read the documentation</a>.</p><h2 id="downloads-over-mix">Downloads over Mix</h2><p>Logos Storage can now route downloads over the Logos Mix network, with RLN providing spam protection, so the node downloading a file cannot be linked to the content it downloads.&nbsp;</p><p>At this stage only the downloader is protected, as nodes providing files are not yet anonymised, and performance improvements are planned for upcoming testnet versions.&nbsp;</p><p>Logos Storage also now works as a backend for the Logos package manager, allowing users to fetch packages from the Storage network instead of relying primarily on GitHub.</p><p>Read more about&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://github.com/logos-storage/transport-over-mix/">data transport over Mix</a>.</p><h2 id="rln-in-delivery">RLN in Delivery</h2><p>Delivery now uses Rate-Limiting Nullifiers (RLN) through the new RLN module, allowing each sender to prove they are within their message allowance without revealing which member they are.&nbsp;</p><p>RLN proof validation will be switched on roughly two weeks after release, to allow a smooth transition.&nbsp;</p><p>RLN, Mix, and Service Discovery also ship as standalone modules that can be more easily integrated with others, and Chat now uses RLN and Mix through Delivery.</p><p><a target="_blank" rel="noopener noreferrer" href="https://github.com/logos-co/logos-lez-rln">Learn more about the RLN LEZ module</a>.</p><h2 id="staking-bridged-funds-with-channel-notes">Staking bridged funds with Channel Notes</h2><p>When funds are bridged into a zone such as the LEZ, they are held on Logos Blockchain as notes belonging to that zone's channel.&nbsp;</p><p>With the newly introduced Channel Notes mechanism, the zone's sequencers can stake those bridged funds on the base layer, so value bridged into a zone helps secure the base layer the zone relies on.</p><h2 id="logos-sql">Logos SQL</h2><p>Logos SQL is a new zone that turns a blockchain channel into a distributed SQL database.&nbsp;</p><p>Developers write SQL transactions to the channel, and each node applies them to a copy of the database kept locally on its own machine. We welcome developers to start building database-backed applications with it now, using the SQL they already know.&nbsp;</p><p>The testnet is still under active development and the network may be reset, but because the SQL database is stored locally, it can be rebroadcast after a reset, or when mainnet launches, instead of being rebuilt from scratch.</p><h2 id="lez-incremental-state-updates">LEZ incremental state updates</h2><p>The state update model for the LEZ has changed. LEZ programs now describe account changes as incremental diffs, recording only what has changed, instead of writing out the full state of every account after each update.&nbsp;</p><p>This is faster and simpler for developers, and it is a breaking change, so existing LEZ programs will need to be updated.&nbsp;</p><p>The change has been on the roadmap for some time, and feedback from building on the LEZ made it clear that large breaking changes are better made now, while the ecosystem is small, than later.&nbsp;</p><p>Developers should expect some disruption at first, with smaller breaking changes possible in Testnet v0.4, after which breaking changes to the LEZ are expected only where security requires them.</p><h2 id="monero-and-ethereum-wallets">Monero and Ethereum wallets</h2><p>Basecamp now includes a Monero wallet, with balances, sending with a review step, receiving by QR code, transaction history, and wallet management.&nbsp;</p><p>It also includes EVM wallet apps and modules, including an Ethereum wallet, a JSON-RPC client, a keystore, a signer, a token lists manager, and an Ethereum verified proxy.&nbsp;</p><p>The verified proxy runs an Ethereum light client within Logos and checks each RPC response against cryptographic proofs, so a provider that returns false data produces an error instead of a wrong balance.&nbsp;</p><p>Together, these let people who already hold Monero or Ethereum-based assets manage them from Basecamp on their own machine, providing a local-first alternative to centralised wallet services and RPC interfaces.</p><h2 id="other-changes-in-this-release">Other changes in this release</h2><p>In Logos Core,&nbsp;<i>logosctl</i> has been added as a new single command-line tool that replaces&nbsp;<i>logoscore</i>,&nbsp;<i>lgpm</i>, and&nbsp;<i>lgpd</i>. Basecamp and Logos Core now also run on Windows, with an installer and a portable mode.</p><p>In Basecamp, applications can call one another through intents and deep links, the Blockchain Dashboard and explorer have been given a refreshed interface, and there have been general stability and interface improvements.</p><p>Chat now keeps message history across sessions, Delivery can retrieve messages missed while offline from store nodes, and the Reliable Channel API can split large messages and reassemble them on arrival. Note that accounts do not yet persist across different Chat sessions, and reopening chat creates a new account. Account persistence is coming soon.</p><p>Mix is also now available to developers through the Messaging API, and the Mix module allows node operators to run mix nodes.</p><p>In the LEZ, public transactions now carry transaction fees, zones can exchange messages asynchronously, and programs support events, upgrades after deployment, and deployment sharding. Bridging withdrawals are also included.</p><p>On Logos Blockchain, uncle references improve Cryptarchia's estimate of total stake, the Blend Network has a first version of message compression and failure detection, and the mempool specification has been published.</p><p><a target="_blank" rel="noopener noreferrer" href="https://roadmap.logos.co/testnets/v03-release">Read the full Testnet v0.3 release notes</a>.</p><h2 id="getting-started">Getting started</h2><p>Testnet v0.3 is available now. To run the stack and the new wallets on your own machine, download and install Basecamp at&nbsp;<a target="_blank" rel="noopener noreferrer" href="http://logos.co/basecamp">logos.co/basecamp</a>.</p><p>If you want to run a node and contribute capacity to the network, or you are running into issues with setting up your node, see the&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://roadmap.logos.co/testnets/logos-node-operator-guide">node operator guide</a>.</p><p>Developers can start building on Logos SQL and the LEZ today. Read more about the architecture of the Logos stack at&nbsp;<a target="_blank" rel="noopener noreferrer" href="http://docs.logos.co">docs.logos.co</a>.</p><p>If you have questions, feedback, or ideas about what Logos is building, join the conversation on the&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://forum.logos.co/">Logos forum</a>.</p><p><strong>Build the parallel.
