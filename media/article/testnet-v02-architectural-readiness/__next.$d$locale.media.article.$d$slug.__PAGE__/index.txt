1c:T221e,<p>On 30 June, Logos Testnet v0.2 went live to the operators already running nodes across the network. It has spent the weeks since being tested and hardened under real conditions. Now we are opening it up, bringing more people in to test the modules, run a node, and build.</p><p>For a module-by-module overview of what shipped in the latest update read our previous&nbsp;<a href="/media/article/testnet-v02-live">technical announcement</a>. In this article, we would like to provide a high-level overview of what the goal of the testnet is, where it fits on the roadmap, and the next steps from here.</p><p>Testnet v0.1 was the convergence of the Logos stack. It proved that messaging, storage and consensus could be brought together and made to work as one. v0.2 is about architectural readiness.&nbsp;</p><p>Testnet v0.2 deploys and hardens the core protocols of the modular stack, Logos Messaging, Logos Storage and Logos Blockchain, and brings the network's foundational privacy primitives online.</p><p>While still in the testnet phase, the stack is evolving into a usable, private-by-default network, with the first of its privacy and decentralisation features now live and being hardened.</p><p>For those ready to start experiencing these updates,&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://logos.co/basecamp">install Logos Basecamp</a> to run a node and begin testing the modules directly.</p><h2 id="hardening-privacy-with-blend">Hardening privacy with Blend</h2><p>Logos Testnet v0.2 is where the first pieces of a private-by-default architecture start to fall into place.&nbsp;</p><p>The clearest example is the&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://docs.logos.co/blockchain/concepts/about-the-blend-network#participating-in-the-blend-network">Blend Network</a>, which pushes privacy past the transaction and into consensus itself.</p><p>Blend adds anonymity for block proposers, and together with Cryptarchia, it delivers the private proof-of-stake consensus protocol for the Logos blockchain. With Blend functioning as designed, the operators proposing blocks can no longer be picked out by anyone watching network traffic.&nbsp;</p><p>Node operators can now participate in the Blend network, helping to improve block proposer anonymity and secure the network.</p><p>Privacy now covers more than the contents of a transaction; it reaches the consensus process that secures the chain, moving Logos towards Private Proof-of-Stake.&nbsp;</p><figure class="image"><img style="aspect-ratio:1920/686;" alt="About_the_Blend_Network.png" src="/media-images/About_the_Blend_Network_2931f79f33-59dd1c41-750.webp" srcset="/media-images/About_the_Blend_Network_2931f79f33-59dd1c41-750.webp 750w, /media-images/About_the_Blend_Network_2931f79f33-59dd1c41-1400.webp 1400w" sizes="(max-width: 767px) calc(100vw - 32px), 700px" width="1920" height="686" loading="lazy" decoding="async"><figcaption>Disseminated Blend Network cover traffic (blue lines) obscuring a data message (yellow lines).</figcaption></figure><p>With Blend now implemented, the Logos stack takes another step towards solving the privacy challenges involved in the&nbsp;<a href="/media/article/how-blockchain-transactions-leak-data">supply chain of a blockchain transaction</a>. Reliance on centralised servers and traceable routing protocols makes it impossible to transact without the risk of being identified. Blend brings the stack one step closer to achieving end-to-end privacy that goes far beyond cryptographic security.</p><p>The core modules have matured alongside Testnet v0.2, and are now all able to be run from within a Logos node. Logos Messaging offers a new delivery layer with a cleaner API for reliable message delivery. Logos Storage features several architectural improvements, including better NAT traversal which can be leveraged across the Logos stack</p><p><i>The&nbsp;</i><a target="_blank" rel="noopener noreferrer" href="https://docs.logos.co"><i>documentation</i></a><i> provides further insight on Logos modules, with specifications that describe each protocol implementation.</i></p><h2 id="interoperation-and-usability-in-practice">Interoperation and usability in practice</h2><p>Testnet v0.2 also provides the functionality that allows sovereign zones on the Logos blockchain to knit together.&nbsp;</p><p>Token bridging,&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://docs.logos.co/blockchain/zone-sdk/bridge-assets-between-blockchain-and-zone">exposed through the Zone SDK</a>, is the foundation for interoperation across sovereign Zones: the way assets and state move between independent execution environments, and the groundwork for an interoperable network of Zones.&nbsp;</p><p>Decentralised sequencing has also been delivered, allowing each Zone to order its own transactions without a central sequencer. This is ready to enable at a later stage of testing to make the network more resilient and independent.</p><p>The latest version of the Logos testnet also improves accessibility for users and developers. Every module now lives inside&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://logos.co/basecamp">Logos Basecamp</a>, a single, local-first application that bundles everything you need to use Logos.</p><p>This means all core aspects of the Logos stack can now be accessed from one desktop application rather than being wired together by hand. The Logos node can be run through Basecamp too, making it easy to join and participate in the testnet, or to contribute to its underlying privacy by running the Blend protocol.&nbsp;</p><p>Testnet v0.2 opens the door to external validators, making it easier than before for new operators to be onboarded to the Logos ecosystem.</p><p>Builders can work with the Logos stack today, and&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://logos.co/lambda-prize">λ Prizes</a> are awarded to developers for creating privacy-preserving applications underpinned by Logos infrastructure.</p><p><i>Start with the&nbsp;</i><a target="_blank" rel="noopener noreferrer" href="https://docs.logos.co"><i>documentation</i></a><i>, or run&nbsp;</i><a target="_blank" rel="noopener noreferrer" href="https://logos.co/basecamp"><i>Basecamp</i></a><i>.</i></p><h2 id="what-s-next">What's next</h2><p>Testnet v0.2 is the moment where the Logos stack is architecturally sound, laying a foundation for builders to start building privacy-preserving applications and for end-users to try them out. The pieces are in place, core privacy primitives are deployed, and the network is stable enough to experiment with and join as a node operator.</p><figure class="image"><img style="aspect-ratio:1920/1080;" alt="ROAD_MAP_5.png" src="/media-images/ROAD_MAP_5_2bc47e0687-6b834b2f-750.webp" srcset="/media-images/ROAD_MAP_5_2bc47e0687-6b834b2f-750.webp 750w, /media-images/ROAD_MAP_5_2bc47e0687-6b834b2f-1400.webp 1400w" sizes="(max-width: 767px) calc(100vw - 32px), 700px" width="1920" height="1080" loading="lazy" decoding="async"><figcaption>This roadmap is our journey to mainnet: what we're prioritising now and where we're headed. It's a starting point for conversations, not a promise of specific features, functionality or timing. Timing might shift and the path will evolve as we build.</figcaption></figure><p>Work is continuing across all Logos modules as we progress towards Testnet v0.3, which will pave the way for an ecosystem to develop on top of the privacy-preserving, modular infrastructure.</p><p>There are a few ways to get involved with Logos Testnet v0.2:</p><ul><li>Run a node through&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://logos.co/basecamp">Logos Basecamp</a> and help test the network in the wild;</li><li><a target="_blank" rel="noopener noreferrer" href="https://logos.co/get-started">Start building on Logos</a> and explore&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://logos.co/lambda-prize">λ Prizes</a> to win prizes for solving challenges and developing applications;</li><li>Or read the&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://docs.logos.co">documentation</a> for a more in-depth look at the foundational Logos infrastructure and modules.</li></ul><p>Testnet v0.1 brought the pieces of Logos together into a unified technology stack. With Testnet v0.2, we have reached the stage where the architecture is ready to be expanded and built upon.&nbsp;</p><p>As we progress along the roadmap, we invite contributors to join our mission and to build on the human-centred technology stack that will chart a new course for society.</p><p><strong>Build the parallel.
