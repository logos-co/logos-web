40:T1f40,<p>Logos provides monthly updates on the state of the technology stack and the development of its various modules, giving developers a clear snapshot of what has been built over the past month.</p><p>For developer-focused highlights on X, please follow&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://x.com/Logos_devs">Logos Tech</a>. For broader updates on the Logos movement as a whole, stay tuned to the main&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://x.com/Logos_network">Logos</a> account.</p><h2 id="anonymous-messaging-over-the-mix-network">Anonymous messaging over the mix network</h2><p>The month's most significant milestone was making sender-anonymous messaging a capability developers can pick up and use. LIONESS payload encryption for Sphinx was merged into the mix protocol implementation and confirmed to integrate with Logos Delivery without issues, preserving message integrity end to end.</p><p>Documentation was then published covering&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://docs.logos.co/messaging/chat-module/send-anonymised-messages-over-the-mix-network">how to send anonymised messages over the mix network</a> on testnet v0.2, with messages routed sender-unlinkably through a three-hop mixnet via Logos Chat. Mix-based chat with DoS protection was also presented and demoed at the&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://www.youtube.com/watch?v=6TRcUIYt_wE">IFT Town Hall</a>.</p><h2 id="logos-technology-stack-updates">Logos technology stack updates</h2><h3 id="logos-core">Logos Core</h3><p>Basecamp moved to a dockable workspace layout, added keyboard shortcut handling and an ARM Linux build, and now presents a single install and upgrade confirmation dialog listing any dependency changes.</p><h3 id="storage">Storage</h3><p>Storage research focused on hidden services, with a purpose-built simulator developed to model a hidden service over the mix network using guards and vanguards, followed by a free-route simulator for studying path selection and the malicious-path problem.</p><p>Work also progressed on NAT traversal ahead of Testnet v0.2.1, with several improvements made that significantly improve node connectivity.</p><p>Elsewhere, all wire protocols were migrated to nim-protobuf-serialisation in place of hand-written serialisers, and the Logos Storage UI was brought largely into line with the Logos Design System.</p><h3 id="messaging">Messaging</h3><p>The Messaging API progressed closer towards main feature completeness. RLN was isolated into a self-contained module usable by any protocol, the FFI node lifecycle was unified and the legacy surface dropped, structured API layers were introduced, and an in-repo end-to-end test suite was added.</p><p>Logos Chat advanced towards Beta with GroupV2 client integration, group names and descriptions, membership changes surfaced as events, and key bundles now published over Logos Delivery. The Reliable Channel API continued to stabilise, and the Rate Limit Manager moved into the messaging client layer.</p><h3 id="blockchain">Blockchain</h3><p>Testnet v0.2 completed its rollout across the stack, with the Logos Blockchain node 0.2.0 released alongside the blockchain module and dashboard, the LEZ module, wallet UI, indexer, and explorer. An iterative update, Testnet v0.2.1, is expected to roll out on 5 August 2026.</p><p>On the Logos Execution Zone, a Keccak speedup for the Risc0 backend cut proving time by roughly half, and async cross-zone messaging reached review complete with a browser demo showing send, finalise, and receive timings live. Nimbos merged libp2p AutoNAT v2 and wired SDP validator operations into the ledger.</p><h3 id="anoncomms">AnonComms</h3><p>Two long-running research threads reached publication. The&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://lip.logos.co/anoncomms/raw/logos-oracle-zone.html">oracle mechanism specification</a> is now published as a LIP, laying the groundwork for the Decentralised Oracle Network, and the&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://lip.logos.co/anoncomms/raw/payment-streams.html">payment streams on-chain specification</a> was published alongside an end-to-end demo of payment streams with Store integration.</p><p>The Zerokit v3.0.0 rearchitecture is close to release, and a working RLN membership management module and UI were deployed on testnet, including an experiment using a Keycard device certificate as an authentication method.</p><h3 id="post-quantum-benchmarks-and-research">Post-quantum benchmarks and research</h3><p>Post-quantum work continued to be a recurring theme, with benchmarks of cryptographic primitives conducted on a Raspberry Pi 5 and Apple M3, and Blend post-quantum primitive candidates finalised.</p><p>An anonymous communications simulation framework with two closed-form anonymity predictions was built, a survey of turn-assignment mechanisms for channel sequencing was completed, and the Checkpoint-based Fast Bootstrapping RFC was opened for review.</p><h3 id="documentation">Documentation</h3><p>Logos Storage documentation is being revamped, with a view to eventually add it to the documentations available on&nbsp;<a target="_blank" rel="noopener noreferrer" href="http://docs.logos.co">docs.logos.co</a>. A set of runnable tutorials was also added to the libp2p module, with continuous integration checks on the tutorial code.</p><p>A closer look at the user-facing launcher for the Logos stack was also published in&nbsp;<a href="/media/article/basecamp-v02">Basecamp in Testnet v0.2</a>.</p><p>The documentation for the Logos stack is maintained at&nbsp;<a target="_blank" rel="noopener noreferrer" href="http://docs.logos.co">docs.logos.co</a>, and the&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://roadmap.logos.co/testnets/logos-node-operator-guide">Node Operator Guide</a> remains the best starting point for running a node on Logos Testnet v0.2.</p><h2 id="logos-broadcast-network-and-circles">Logos Broadcast Network and Circles</h2><p>Throughout July, Logos contributors continued to host online and IRL Circles around the world, creating digital and physical space to solve real-world problems with privacy-preserving technology.</p><p>Logos contributors&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://luma.com/12ev9180">also headed to DWeb in Berlin last month</a>, where we hosted four days of talks, technical sessions, and fostering collective action to support human freedom. Check out&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://x.com/Crypto_marina/status/2077385682008363116?s=20">this recap of the event on X</a>.</p><p>The Logos Broadcast Network continued to deliver regular programming, from Dev Club sessions and weekly technical updates to office hours every Friday at 14:00 UTC.
