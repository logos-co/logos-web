12:T1f6f,<p>Logos provides monthly updates on the state of the technology stack and the development of its various modules, giving developers a clear snapshot of what has been built over the past month.</p><p>September closed with the release of Logos Testnet v0.3, bringing proof-of-work participation, decentralised sequencing, anonymous downloads, and the first wallets for existing assets to the stack.</p><p>The updates listed here are some of the most important highlights from the past month. Work progresses on many facets of the stack simultaneously, and a more complete, technical breakdown is available at&nbsp;<a target="_blank" rel="noopener noreferrer" href="http://roadmap.logos.co">roadmap.logos.co</a>.</p><p>For developer-focused highlights on X, please follow&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://x.com/Logos_devs">Logos Tech</a>. For broader updates on the Logos movement as a whole, stay tuned to the main&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://x.com/Logos_network">Logos</a> account.</p><h2 id="logos-testnet-v0-3-is-live">Logos Testnet v0.3 is live</h2><p><a href="/media/article/logos-testnet-v03-live">Logos Testnet v0.3</a> was released on 30 September, with improvements across almost every part of the stack, from how new participants join the network to how files and messages move privately between peers.</p><p>Node operators should update their clients, and developers will need to update existing LEZ programs, since the move to incremental state updates is a breaking change. The&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://docs.logos.co/run-a-node">node operator guide</a> covers running a node on the new release.</p><p>With the launch of testnet v0.3, EmPoWering is now operational, allowing new participants gain testnet tokens on the Logos Blockchain by performing computational work, which removes the centralised, traceable on-ramps networks usually rely on.</p><p>The Logos Execution Zone now supports decentralised sequencing, which sees a set of sequencers taking turns proposing blocks on a schedule enforced by the Logos Blockchain, each checking the blocks the others produce.</p><p>Logos Storage can now also route downloads over the Logos Mix network. At this initial stage, file providers are not yet shielded by the Mix network. Delivery now uses Rate-Limiting Nullifiers through the new RLN module, and RLN, Mix, and Service Discovery also now ship as standalone modules.</p><p>Other major updates in the latest version of testnet include Logos SQL, a distributed SQL database that runs as a Logos Blockchain zone, and Channel Notes that allows tokens bridged on the base layer to be staked by a zone’s sequencers.</p><p>Basecamp also now includes Monero and Ethereum testnet wallets, the latter with a verified proxy that checks each RPC response against cryptographic proofs.</p><h2 id="the-logos-mix-network-specification">The Logos Mix Network specification</h2><p>The&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://lip.logos.co/anoncomms/raw/logos-mixnet.html">Logos Mix Network specification</a> has been published, setting out the configuration of the anonymisation layer that Logos services run over. It is an opinionated instantiation of the libp2p mix protocol suite, so any node that follows it can operate as a Logos Mixnet node and interoperate with the rest.</p><p>All nodes are equal participants, meaning that for a given message a node may be the sender, an intermediary or the exit. Paths are three hops long with each node chosen at random from the discovered pool, every node must hold an RLN membership in order to send or forward, and each hop verifies the proof it receives before generating a fresh one for the packet it passes on.</p><h2 id="poseidon2-in-circom-rln-and-zerokit">Poseidon2 in circom-rln and Zerokit</h2><p>A Poseidon2 circuit was shipped in&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://github.com/vacp2p/circom-rln/pull/1">circom-rln</a> with an accompanying benchmark report, and&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://github.com/vacp2p/zerokit/pull/437">Zerokit</a> has added Poseidon2 examples for Rust, C, Nim and JavaScript along with FFI and WASM support.</p><p>Zerokit is the zero-knowledge toolkit behind RLN, the rate limiting that keeps spam off Logos Messaging without requiring identities. Hashing is the dominant cost in generating those proofs, so cheaper hashing means cheaper proofs on every client that produces one.</p><h2 id="time-based-path-selection-for-hidden-services">Time-based path selection for hidden services</h2><p>A new discussion opened on the research forum covering&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://forum.research.logos.co/t/hidden-service-time-based-path-selection/730">time-based path selection for hidden services over the Logos Mixnet</a>.&nbsp;</p><p>Two designs were tested for how well they resist de-anonymisation: sampling complete paths with per-path rotation, and a fixed sparse topology with degrees configured according to the anonymity required.</p><p>The Mix path selection specification is being defined on the back of this work.</p><h2 id="the-de-mls-boundary-contract">The de-MLS boundary contract</h2><p>A new research discussion was opened on the&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://forum.research.logos.co/t/de-mls-boundary-contract/727">de-MLS boundary contract</a>.&nbsp;</p><p>De-MLS runs a decentralised MLS conversation driven purely by the application that calls it, and the document examines what it guarantees at each of its boundaries, to the application, to the consensus service, and to MLS.</p><h2 id="prize-winners">λPrize winners</h2><p>Three builders won λPrizes this month.</p><p>pramadanif built a&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://github.com/logos-co/lambda-prize/blob/master/solutions/LP-0002.md">private multisig for the LEZ</a>. Members approve spending from a shared fund, and the chain records that enough of them agreed without revealing who.</p><p>Timidan built&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://github.com/logos-co/lambda-prize/blob/master/solutions/LP-0003.md">DistributionX</a>, a private airdrop. People claim from a list without the list, or their place on it, ever becoming public.</p><p>aegonmyy built&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://github.com/logos-co/lambda-prize/blob/master/solutions/LP-0008.md">an AI agent that runs on the Logos stack with its own private wallet</a>. It spends within a limit its owner sets, and asks over encrypted chat before going beyond it.</p><h2 id="logos-broadcast-network-and-circles">Logos Broadcast Network and Circles</h2><p>Throughout September, Logos contributors continued to host online and IRL Circles around the world, creating digital and physical space to solve real-world problems with privacy-preserving technology.</p><p>The Logos Broadcast Network continued to deliver regular programming, from Dev Club sessions and weekly technical updates to office hours every Friday at 14:00 UTC. Join these office hours to learn more about building on the Logos stack or to get help with specific issues.</p><p>Full schedules and participation details are available at&nbsp;<a href="/logos-broadcast-network">press.logos.co/calendar</a> and&nbsp;<a target="_blank" rel="noopener noreferrer" href="http://logos.co/circles">logos.co/circles</a>. For a full list of upcoming Logos events, check out the event page on&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://luma.com/logosevents">Luma</a>.</p><p>To get the latest developer updates from the Logos stack, follow&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://x.com/Logos_devs">Logos Tech</a> on X.
