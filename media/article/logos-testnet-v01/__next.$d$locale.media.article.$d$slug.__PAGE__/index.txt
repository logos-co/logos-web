11:T2dfe,<p>Today marks a defining moment for Logos with the launch of testnet v0.1; not as a traditional release, but as a convergence milestone and a significant step toward a socio-economic system powered by private-by-default infrastructure.</p><p>For the past several years, Logos has been building the individual components of a technology stack designed to revitalise civil society: consensus, execution, networking, storage, and messaging. All protocols have been developed independently, with their own roadmap and validation process, but with mechanical symphony in mind. Testnet v0.1 is the first time these systems are packaged together into a unified, modular stack and made available for developers to run and experiment with.</p><p>Testnet v0.1 is focused on backend validation and module integration. It is designed to stress test infrastructure, expose APIs, and verify how protocols interact under real network conditions.&nbsp;</p><p>This first version of the testnet is purely an initial architecture for the unified Logos stack; future releases will introduce more functionality and improvements.</p><p>Developers can start experimenting with testnet v0.1, explore sample applications, view RFPs, and submit ideas and proposals on the new&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://build.logos.co/"><i><strong>Logos Builder Hub</strong></i></a> now.&nbsp;</p><h2 id="a-modular-stack-private-by-default">A modular stack, private by default</h2><p>The Logos tech stack is organised into distinct layers, each with a clear responsibility. Each layer was developed with specific deliverables for testnet v0.1, and together they prove an end-to-end vertical system behaviour for the first time. Two demo apps have been developed to showcase how the modular system can function&nbsp;<i>(more below).</i></p><h3 id="logos-kernel">Logos “Kernel”</h3><p>At its foundation sits&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://github.com/logos-co/logos-liblogos"><strong>liblogos</strong></a><strong>&nbsp;</strong>— a microkernel-like foundation responsible for the minimal primitives required to run decentralised systems. In its current state, the “kernel” is operational and able to manage all layers of the stack. For example:</p><ul><li>`liblogos` loads modules from GitHub (for now; in future, the plan is to load modules from Logos Storage).</li><li>Logos Basecamp hosts module UIs.</li><li>Operators can run a Logos node and choose which modules they would like to install and manage.</li><li>The new logos-module library and CLI tool abstract module interaction.</li></ul><h3 id="networking-layer">Networking Layer</h3><p>Above the “kernel” is the networking layer. This layer handles peer discovery, connection management, and privacy-preserving communication. It enables nodes to find one another, establish secure channels, and route messages.</p><p>For testnet v0.1, the networking layer is operational in its early form, with plans to update it in the future:</p><ul><li>Mixnet and POCs are usable, but in development.</li><li>Capability discovery is active (although in early stages of development).</li></ul><h3 id="modules">Modules</h3><p>On top of the networking layer sit modules – pluggable, composable components that extend the system with higher-level functionality. Blockchain, execution zones, messaging, storage, and other capabilities are implemented as modules. They are independent but interoperable, communicating through well-defined interfaces exposed by Logos Core.</p><p><strong>Blockchain:</strong> the following elements of the blockchain are available in testnet v0.1:</p><ul><li>Cryptarchia PoS implemented, with the privacy-preserving element to be added.</li><li>Logos Execution Zone (LEZ) sequencer, indexer, and block explorer with the Bedrock node to enable end-to-end testing.</li></ul><p><strong>Messaging:&nbsp;</strong>Private communication has been designed into two primary modules:</p><ul><li>Delivery to easily send reliable messages.</li><li>Chat enabling fundamentals for private, secure messaging, including E2EE, perfect forward secrecy, double-ratchet encryption, conversation initialisation, and payload handling.</li></ul><p><strong>Storage:&nbsp;</strong>Decentralised file sharing with CID-based retrieval.</p><p>View all the&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://github.com/logos-co/logos-docs"><strong>docs here</strong></a>.</p><h2 id="logos-basecamp">Logos Basecamp</h2><p>Logos Basecamp is a complete distribution that bundles liblogos, the default modules, and UI packages into a usable product. It allows the user to easily interact with simple apps built on the various modules.&nbsp;</p><p>Install the binaries on the new&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://build.logos.co/"><strong>Logos Builder Hub</strong></a>.</p><p><img alt="Logos Package Manager.png" src="/media-images/Logos_Package_Manager_9ae97dce66-a85a1fb0-750.webp" srcset="/media-images/Logos_Package_Manager_9ae97dce66-a85a1fb0-750.webp 750w, /media-images/Logos_Package_Manager_9ae97dce66-a85a1fb0-1400.webp 1400w" sizes="(max-width: 767px) calc(100vw - 32px), 700px" width="1999" height="1107" loading="lazy" decoding="async"></p><h2 id="beyond-testnet-v0-1-the-roadmap-to-mainnet">Beyond Testnet v0.1 - The roadmap to mainnet</h2><p>Three testnet phases reduce risk progressively before an irreversible mainnet launch. Each phase is a go/no-go gate in which we do not advance until questions are answered.&nbsp;<i>The following represents the plan, but as with all technology, the roadmap is subject to change.</i></p><h3 id="v0-1-architectural-validation">v0.1: Architectural Validation</h3><p>The vertical stack operates as one coherent system, but is in its early architecture and will be improved and built upon. The base layer, LEZ, CLI tooling, and demo applications run together in an integrated environment, validating end-to-end behaviour across modules and proving the architecture in practice.</p><h3 id="v0-2-improved-usability">v0.2: Improved Usability</h3><p>The stack becomes usable in real-world conditions, and new features will be introduced that continue to improve the usability of modules. External validators will participate, cross-module coordination will stabilise, and builder friction will be significantly reduced through improved tooling, documentation, and integration. This version of the testnet will see architectural improvements across the entire stack.</p><h3 id="v0-3-ecosystem-dynamics">v0.3: Ecosystem Dynamics</h3><p>The ecosystem will demonstrate sustainability. Meaningful applications will emerge, liquidity primitives will be activated, distribution will expand, and the system will be tested under stress and adversarial conditions.</p><h3 id="mainnet-system-viability">Mainnet: System Viability</h3><p>The mainnet will launch with a fully integrated, audited stack. Liquidity, distribution, validator diversity, and launch-day applications will be in place. Core economic and coordination loops will operate as self-sustaining systems.</p><p><img alt="Logos Testnet Roadmap.png" src="/media-images/Logos_Testnet_Roadmap_c2198509e0-078adecc-750.webp" srcset="/media-images/Logos_Testnet_Roadmap_c2198509e0-078adecc-750.webp 750w, /media-images/Logos_Testnet_Roadmap_c2198509e0-078adecc-1400.webp 1400w" sizes="(max-width: 767px) calc(100vw - 32px), 700px" width="1440" height="800" loading="lazy" decoding="async"></p><h2 id="demo-apps-showcasing-the-stack">Demo apps showcasing the stack</h2><p>Two demo apps have been built by the Logos team to showcase the various modules and interoperability between them.</p><h3 id="atomic-swaps">Atomic Swaps</h3><p>The Atomic Swaps sample app demonstrates trust-minimised cross-chain exchange between LEZ (λ) and Ethereum using an HTLC-based mechanism. A maker sells λ for ETH, while a taker completes the swap, with built-in refund paths if timeouts occur.&nbsp;</p><p>The app integrates the LEZ Wallet, Blockchain module, and Ethereum wallet tooling, showcasing cross-chain coordination through Logos Core. While Ethereum-side activity is publicly traceable, private LEZ accounts protect participant identity, highlighting how Logos combines interoperability with structural privacy.</p><ul><li><a target="_blank" rel="noopener noreferrer" href="https://github.com/logos-co/eth-lez-atomic-swaps/"><strong>GitHub</strong></a></li></ul><h3 id="multisig">Multisig</h3><p>The Multisig sample app enables secure, privacy-preserving shared custody of assets, requiring multiple signatures to authorise transactions. It protects treasuries, team funds, and shared wallets without revealing signers or balances.&nbsp;</p><p>The app leverages threshold signatures, zero-knowledge proofs, and privacy-preserving MPC to ensure approvals are verifiable while keeping individual participation confidential. By integrating with Logos Core modules, it demonstrates secure coordination, signer rotation, and ZK-enabled authorisation, highlighting Logos’ ability to support private, multi-party financial interactions for DAOs, corporate treasuries, and collaborative funds.</p><ul><li><a target="_blank" rel="noopener noreferrer" href="https://github.com/jimmy-claw/lez-multisig"><strong>GitHub</strong></a></li></ul><h2 id="the-logos-builder-hub">The Logos Builder Hub</h2><p>In addition to releasing the Logos Testnet v0.1, the team has introduced the Logos Builder Hub - a hub for developers to start experimenting with the tech stack, download Logos Basecamp, review and start work on new RFPs, and explore and submit ideas they want to see built.&nbsp;</p><p><a target="_blank" rel="noopener noreferrer" href="https://build.logos.co/"><i><strong>Explore the Builder Hub now.</strong></i></a></p><h3 id="download-logos-basecamp">Download Logos Basecamp</h3><p>Logos Basecamp is a complete distribution that bundles the kernel, the default modules, and UI packages into a usable product. It allows the user to easily interact with simple apps built on the various modules.</p><h3 id="request-for-proposals-rfps">Request For Proposals (RFPs)</h3><p>The Logos RFP programme invites developers and teams to submit proposals to build and launch production-ready applications on the Logos stack. Through milestone-based funding, talented teams can bring their ideas to life, showcase their work to the ecosystem, and deliver real, market-ready apps. The programme supports projects across developer tooling, integrations, and community-focused applications.&nbsp;</p><p>View more on&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://github.com/logos-co/rfp"><strong>GitHub</strong></a>.</p><h3 id="ideas-repo">Ideas Repo</h3><p>Along with RFPs, the Builder Hub includes a list of ideas submitted by both Logos core contributors and community members. These are ideas for apps that would be useful for the ecosystem and help deliver on the mission to revitalise civil society. While important to the mission, these are designed for inspiration and connection over funding.&nbsp;</p><p>View more on&nbsp;<a target="_blank" rel="noopener noreferrer" href="https://github.com/logos-co/ideas"><strong>GitHub</strong></a>.</p><p>&nbsp;</p><p><i>Logos is pioneering a new era of freedom; join the mission and help build the tools to revitalise civil society.&nbsp;</i></p><p><a target="_blank" rel="noopener noreferrer" href="https://build.logos.co/"><strong>Builder Hub</strong></a></p><p><a target="_blank" rel="noopener noreferrer" href="https://github.com/logos-co/logos-docs"><strong>Logos Docs</strong></a></p><p><a target="_blank" rel="noopener noreferrer" href="https://logos.co/testnet-v01-faqs"><strong>Testnet v0.1 FAQs</strong></a></p>a:["$","$L10",null,{"bodyHtml":"$11","content":[]}]
