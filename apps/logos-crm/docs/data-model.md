# Logos CRM data model

The PostgreSQL schema for `apps/logos-crm`, defined in
[`src/server/db/schema.ts`](../src/server/db/schema.ts) and applied by the generated migrations in
[`drizzle/`](../drizzle). Drizzle is the single source of truth; the checked-in SQL is produced from
it by `db:generate`.

## Conventions

- Primary keys are UUIDs generated by Postgres (`gen_random_uuid()`).
- Timestamps are `timestamp with time zone`, defaulting to `now()`.
- Directory records carry `created_at`, `updated_at`, and an integer `version`.
- Controlled values are Postgres enums whose allowed values come from
  [`src/contracts/values.ts`](../src/contracts/values.ts).
- Link, activity, and task tables use `ON DELETE CASCADE` so deleting a parent removes its links,
  activities, and tasks.
